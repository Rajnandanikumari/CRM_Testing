# SaaS-Based CRM Application Testing Project

## Project Overview

Performed Manual Testing and API Testing on a SaaS-based CRM (Customer Relationship Management) Application. The objective was to validate business workflows, user roles, functionality, API integrations, and browser compatibility to ensure a seamless user experience for clients and employees.

## Application Type

**Software as a Service (SaaS) CRM Application**

The application provides centralized management of:

* Leads
* Projects
* Clients
* HR Activities
* Employees

* Lead Assignment

### HR Activity Management

## Testing Activities Performed

### Manual Testing

* Created and executed test cases.
* Performed positive and negative testing.
* Validated business workflows.

### Functional Testing

* Verified all CRM modules.
* Tested CRUD operations.
* Validated data flow between modules.

### Cross-Browser Testing

Application was tested on:

* Google Chrome
* Microsoft Edge
* Mozilla Firefox

### UI Testing

* Verified forms, tables, dashboards, and navigation.
* Checked consistency across browsers.

### API Testing

* Performed API testing using Postman.
* Validated request and response payloads.
* Verified status codes and error handling.

### Regression Testing

* Retested functionality after fixes.
* Ensured existing functionality remained stable.

### Role-Based Access Control (RBAC) Testing

* Admin User
* HR User
* Employee User
* Client User

### Defect Reporting

* Logged and tracked defects.
* Verified defect fixes.
